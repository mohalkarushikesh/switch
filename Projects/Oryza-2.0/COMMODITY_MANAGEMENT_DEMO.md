## 🤖 How It Works

### Uncertainty Hedging
```
Every minute:
1. Calculate market stress (VIX, correlations, spreads)
2. If stress > 0.6:
   → Calculate optimal hedge ratio
   → Increase gold allocation
   → Execute protective trades
```

### Inflation Rebalancing
```
Every 30 days:
1. Check current CPI vs expectations
2. If CPI > 3%:
   → Increase commodity allocation
   → Focus on high-correlation assets
   → Maintain 5-20% bounds
```

### Macro Monitoring
```
Continuous tracking:
- Dollar strength → Inverse gold impact
- Real rates → Opportunity cost
- Geopolitical events → Safe haven demand
- Central bank buying → Structural support
```
