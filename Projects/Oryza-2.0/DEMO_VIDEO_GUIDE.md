# 🎥 Oryza Application Demo Video Flow Guide

## 📋 Pre-Recording Checklist
- [ ] Start both frontend and backend using `start_oryza.bat`
- [ ] Clear browser cache for a fresh demo
- [ ] Prepare test data (have a registered user ready)
- [ ] Set screen resolution to 1920x1080 for clarity
- [ ] Close unnecessary tabs/applications
- [ ] Test microphone audio levels
- [ ] Have script/talking points ready

## 🎬 Suggested Video Flow (10-15 minutes)

### 1. Introduction (30 seconds)
- Show Oryza landing page
- Brief voiceover: "Oryza - An AI-powered autonomous investment advisor that revolutionizes wealth management"
- Highlight key features on homepage:
  - AI-Driven Insights
  - Real-Time Analytics
  - Secure Platform
  - 24/7 Autonomous Trading

### 2. User Registration & KYC (1-2 minutes)
- Click "Get Started" → Register
- Fill registration form with sample data
- Show successful registration toast notification
- Navigate to KYC process
- Complete the 3-step KYC verification:
  - Personal Information
  - Document Upload (simulate)
  - Selfie Verification
- Emphasize security and regulatory compliance

### 3. Login & Dashboard Overview (2 minutes)
- Login with credentials
- **Dashboard highlights:**
  - AI-Powered Analytics section (show enhanced UI)
  - Portfolio overview with live values
  - Quick stats cards
  - Real-time market indicators
- Mention: "AI continuously monitors and optimizes portfolio 24/7"
- Point out the gradient backgrounds and modern UI

### 4. Trading Terminal & Investment Categories (3-4 minutes)
**Show each investment category briefly:**

#### 📈 Stocks
- Show real-time price updates
- Demonstrate order placement
- Highlight AI recommendations

#### 🧺 Mutual Funds/ETFs
- Display fund selection interface
- Show NAV tracking
- Mention automated fund switching

#### 🏦 Fixed Income
- Show bond ladder construction
- Explain yield optimization
- Duration management features

#### 🟡 Gold & Metals
- Display commodity prices
- Show hedging capabilities
- Inflation protection features

#### 🏘️ Alternatives
- Show REITs and crypto options
- Explain portfolio diversification
- Liquidity management

#### 🌍 Global Assets
- International market access
- Currency hedging features
- Geographic diversification

#### 🌱 ESG Investments
- Values-based filtering
- Impact metrics
- Sustainability scores

**Key points to emphasize:**
- "Autonomous agents monitor each category 24/7"
- "AI makes real-time decisions based on market conditions"
- Show the live indicators and real-time updates

### 5. AI-Powered Features (2-3 minutes)

#### Market News & Sentiment Analysis
- Show news feed with sentiment indicators (Bullish/Bearish)
- Click "Generate AI Report"
- Show PDF generation progress
- Download and briefly open PDF report
- Highlight professional formatting and insights

#### AI Advisory
- Navigate to AI Advisor page
- Show personalized recommendations
- Explain behavioral analysis features
- Demonstrate goal-based planning

### 6. Personalization & Settings (1-2 minutes)

#### Profile Management
- Go to Profile page
- Update some information
- Show real-time save with success notification
- Demonstrate profile picture upload

#### Settings
- Navigate to Settings
- **General Settings:**
  - Change language to Hindi, then back to English
  - Switch currency to USD, then back to INR
  - Update timezone
- **Display Settings:**
  - **Toggle Dark Mode** (impressive visual change)
  - Show theme persistence across pages

### 7. Advanced Features Overview (1-2 minutes)
- **Goals Planning**: 
  - Show financial goal creation
  - Progress tracking
  - AI suggestions for goal achievement
- **Analytics**: 
  - Display interactive charts
  - Performance metrics
  - Risk analysis
- **Notifications**: 
  - Show real-time alert system
  - Customizable preferences

### 8. Closing & Future Vision (30 seconds)
- Return to dashboard
- Summarize key features:
  - "Multi-agent AI system"
  - "24/7 autonomous trading"
  - "Comprehensive investment coverage"
  - "Bank-grade security"
- Mention upcoming features:
  - Wealth Concierge
  - Voice UI
  - AR portfolio visualization

## 💡 Pro Tips for Recording

### Smooth Navigation
- Practice the entire flow 2-3 times before recording
- Keep mouse movements deliberate and smooth
- Pause briefly (2-3 seconds) on important features
- Use keyboard shortcuts where applicable

### Data Preparation
- Create some sample positions beforehand
- Ensure market data is updating (even if simulated)
- Have 2-3 notifications ready to show
- Pre-generate some historical data for charts

### Visual Impact
- Start in light mode, switch to dark mode mid-demo
- Show loading states and smooth transitions
- Highlight real-time updates by hovering
- Zoom in on important details if needed

### Narration Tips
- Speak clearly and at moderate pace
- Explain what you're clicking and why
- Connect features to real-world use cases
- Emphasize the AI/autonomous aspects
- Use enthusiasm but remain professional

### Technical Highlights
- Briefly mention the tech stack
- Show responsive design (resize browser once)
- Point out WebSocket connections for real-time data
- Highlight performance optimizations

## 🚫 Common Pitfalls to Avoid
- Don't rush through features
- Don't show any errors or broken features
- Avoid dead silence - keep narrating
- Don't forget to show PDF report generation
- Remember to demonstrate dark mode
- Don't spend too long on any single feature
- Avoid technical jargon without explanation
