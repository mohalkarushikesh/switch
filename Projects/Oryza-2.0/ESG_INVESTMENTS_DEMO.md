## 🤖 How It Works

### Controversy Monitoring
```
Every 5 minutes:
1. Scan all holdings for issues
2. Check severity (0-10 scale)
3. If severity > 3:
   → Flag for immediate divestment
4. If severity > 7:
   → Emergency liquidation
5. Record reason and notify user
```

### Values Alignment
```
User selects profile:
- Climate First (60% Environmental)
- Social Impact (60% Social)
- Balanced ESG (33% each)
- Governance Focus (60% Governance)

System screens investments:
→ Calculate values match %
→ Apply exclusion criteria
→ Recommend aligned options
```

### Impact Calculation
```
For each investment:
1. Track specific metrics:
   - CO2 avoided (tons)
   - Jobs created
   - Water saved (gallons)
2. Weight by portfolio %
3. Aggregate total impact
4. Generate impact score
```
