ORYZA PLATFORM - Quick Start Guide
==================================

Prerequisites:
- Python 3.8+
- Node.js 14+
- Git

Steps to Run:
1. Clone/Extract the project
2. Backend Setup:
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python test_api_for_frontend.py

3. Frontend Setup (new terminal):
   cd frontend
   npm install
   npm start

4. Access:
   - Frontend: http://localhost:3000
   - Login: test@oryza.com / test@123

Key Features to Demo:
- Modern Authentication

- Market Intelligence
